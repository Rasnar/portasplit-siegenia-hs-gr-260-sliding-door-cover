# Contributing

Thank you for your interest in improving the Midea Portasplit Cover for Siegenia HS GR 260.

## How to contribute

- Fork the repository and make your changes on a feature branch.
- Update `README.md` if you add new files, preview models, or installation guidance.
- If the change affects fit or print settings, include a short note explaining why.
- When adding OpenSCAD variants, keep the original `default-adapter.scad` as the canonical reference.
- Open a pull request with a clear title and a concise description of what changed.

## Suggested contribution areas

- Add rendered preview images or photographs of printed parts.
- Add height variants or a dedicated “no-hose” version.
- Add installation and assembly photos or a short video link.
- Improve calibration guidance for different filament materials.
- Add alternative rail compatibility notes or adapt the design for other sliding door profiles.

## Reporting issues

Please open an issue if you find:

- fit problems with the Siegenia HS GR 260 rail
- incorrect dimension values or parameter comments
- missing assembly guidance
- broken 3MF/STL exports
